# ASRtools

`ASRtools` is an R package that provides complementary functions for the
[ASReml-R](https://vsni.co.uk/software/asreml-r) family of packages. It bundles
helpers for preparing data, fitting and updating models safely, exploring model
outputs, and performing common matrix operations that arise in mixed-model
analysis.

## Installation

`ASRtools` requires R (>= 4.2.0). Install the latest development version from
the source repository with:

```r
# install.packages("remotes")
remotes::install_github("VSNinternational/asrtools")
```

Or, from a local clone of this repository:

```r
# install.packages("devtools")
devtools::install("path/to/asrtools-main")
```
